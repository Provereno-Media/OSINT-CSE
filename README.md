## 🤝 Contributing

Contributions keep this list alive and useful. Before opening a pull request:

1. **Test your CSE manually** — confirm it returns relevant results for at least 2–3 sample queries.
2. **Add it to the right section** in the tables above (or propose a new section).
3. **Follow the existing row format:** `[Name](link) | Description`.
4. **Found a broken link?** Please [open an issue](../../issues/new/choose) instead of removing it yourself — this helps keep a record of what changed.
